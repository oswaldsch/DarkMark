# DarkMark
DarkMark is a personal note-taking app that support markdown. It is a small project I wanted to do to learn web developing, and I like how it turned out so far.
It stores notes in a local sqlite database, so any notes you write are persistent. Most Markdown features should be supported.

## Features
- Creating, deleting, editing and saving notes
- All basic markdown features
- Popover context menu for some formatting features
- Persistent sqlite database with all your notes
- Edit and Preview mode toggling
